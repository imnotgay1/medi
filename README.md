# 약 알림 (medi)

나만 쓰는 복용 알림 + 체크 앱.

## 기능
- **오늘**: 오늘 먹을 약을 시간순으로 표시, 카드 누르면 체크(다시 누르면 취소). 시간 지났는데 안 먹었으면 빨간색
- **약 관리**: 약 이름·메모·복용 시간(여러 개) 추가/수정/삭제
- **기록**: 최근 2주 하루별 복용 현황, 빠뜨린 약 표시
- **알림**: 정한 시간에 알림 → `먹었어요`(바로 체크) / `10분 뒤`(다시 알림)
- 폰 재부팅해도 알림 유지, 데이터는 폰 안에만 저장

## 빌드
1. GitHub에 `medi` 저장소 만들고 이 폴더 전체 업로드 (`.github` 폴더 포함)
2. Actions 탭 → Build APK 완료 → `medi-apk` 받아서 설치

`app/debug.keystore`는 고정 서명키라서 새 버전을 지우지 않고 덮어 설치할 수 있음.
